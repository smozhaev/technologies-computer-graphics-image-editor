# GrayBit Studio

**GrayBit Studio** — веб-редактор изображений для курса «Технологии компьютерной графики» (2026) — небольшой аналог Photoshop/GIMP. Все алгоритмы работы с пикселями написаны вручную; PNG и JPEG декодирует и кодирует браузер.

Ссылка на приложение: деплой пока не настроен.

## Архитектура (Feature-Sliced Design)

```
src/
  app/        точка входа, провайдеры, глобальные стили
  pages/      editor — страница редактора: собирает виджеты, диалоги, горячие клавиши
  widgets/    menu-bar · toolbar · canvas-viewport · side-panel · status-bar · editor-layout
  features/   open-file · save-file · toggle-channels · pick-color · adjust-levels ·
              zoom-view · resize-image · undo-version
  entities/   document (версии, отмена, текст статуса) · editor (состояние редактора на Zustand, вид)
  shared/     lib/image — все алгоритмы над пикселями (без DOM и React)
              lib/io — декодирование/кодирование браузером, скачивание
              lib/worker — Web Worker и очередь задач · ui — NativeDialog, CanvasView
              config — тема · lib/test — утилиты тестов
```

- Слой импортирует только нижележащие слои; срезы одного слоя друг друга не импортируют.
- Каждый срез и сегмент `shared` открывает публичный API через `index.ts`; импорт в обход него запрещён.
- Импорты через алиас `@/`. Правила проверяет [Steiger](https://github.com/feature-sliced/steiger) в составе `pnpm lint`.

## Производительность

- Холст размером с видимую область: кадр строится только из видимой части изображения, поэтому огромные файлы не упираются в лимиты canvas.
- Вывод разделён на дорогой этап (интерполяция видимой части, кешируется) и дешёвые точечные шаги (маска каналов, предпросмотр уровней, шахматка) — переключение каналов и движение ползунков не пересчитывают интерполяцию.
- Изменение размера считается в Web Worker; исходное изображение передаётся в worker один раз, результат возвращается без копирования.
- История версий не копирует неизменённые буферы; лимит — 10 версий или ~512 МБ.

## Лабораторная работа 1. Цифровое представление изображения

### Возможности

- **Открытие:** «Файл → Открыть…», `Ctrl/Cmd+O` или перетаскивание файла в окно (из нескольких берётся первый). Форматы PNG, JPG/JPEG, GB7. Формат определяется **по сигнатуре файла**, а не по расширению.
- **Сохранение:** «Файл → Сохранить как…» (`Ctrl/Cmd+S`, `Ctrl/Cmd+Shift+S`) — имя файла, формат PNG / JPG / GB7; для JPG — качество 1–100 (по умолчанию 92) и цвет фона под прозрачными пикселями (по умолчанию белый); для GB7 — предупреждение о переводе в оттенки серого и режим маски (Авто / Всегда / Без маски). Сохраняется текущее изображение.
- **Строка состояния:** имя файла; ширина × высота, глубина цвета и формат, например `1920 × 1080 px · 24 бит (RGB) · PNG`, `512 × 512 px · 8 бит (7 + маска) · GB7`. Браузер всегда декодирует в 8-битный RGBA, поэтому настоящая глубина читается из заголовков: PNG (IHDR, tRNS) и JPEG (SOFn). Справа — текущий масштаб.
- **Холст:** размером с видимую область; изображение рисует собственный код, 1 пиксель изображения = 1 CSS-пиксель, резко на HiDPI. Прозрачность показана шахматкой, большие изображения прокручиваются. Пустой холст — кнопка «Открыть изображение»; при перетаскивании файла в окно появляется подсказка «Отпустите, чтобы открыть».
- **Интерфейс:** меню «Файл · Изображение», панель инструментов слева, панели «Каналы» и «Инфо» справа, тёмная тема.
- **Свои реализации:** кодек GB7, яркость BT.601 `Y = 0.299R + 0.587G + 0.114B` (перевод в серый для GB7), наложение прозрачности на цвет фона при сохранении в JPG, вывод изображения на холст.

### Формат GB7

| Смещение | Размер | Поле      | Значение                                     |
| -------: | -----: | --------- | -------------------------------------------- |
|        0 |      4 | сигнатура | `47 42 37 1D`                                |
|        4 |      1 | версия    | `01`                                         |
|        5 |      1 | флаги     | бит 0 — есть маска; биты 1–7 зарезервированы |
|        6 |      2 | ширина    | uint16, big-endian                           |
|        8 |      2 | высота    | uint16, big-endian                           |
|       10 |      2 | резерв    | `0000`                                       |
|       12 |    W×H | пиксели   | по байту, построчно с левого верхнего угла   |

Биты 6–0 пикселя — серое 0–127, бит 7 — маска (1 — видим, 0 — прозрачен), если в заголовке есть флаг маски.

> В тексте задания маска один раз названа «бит 0». Это опечатка: по структуре байта маска — **бит 7**, так и реализовано.

- **Декодирование:** серое масштабируется как `round(v·255/127)`. Ошибки проверяются строго по порядку: длина, сигнатура, версия, нулевой размер, предел 2^28 пикселей, обрезанные данные (до выделения памяти). Зарезервированные биты флагов и лишние байты в конце игнорируются; без флага маски бит 7 игнорируется.
- **Кодирование:** серое `round(Y·127/255)` по BT.601. Маска: «Авто» — ставится, если есть альфа < 128; «Всегда» — бит 7 = альфа ≥ 128; «Без маски» — альфа отбрасывается. Если исходный файл был GB7 с маской, по умолчанию «Всегда», иначе «Авто». Стороны больше 65535 — ошибка.
- Все 128 уровней серого переживают цикл декодирование → кодирование; канонические файлы GB7 воспроизводятся байт в байт (проверено на файлах из LMS в `test-images/`).

### Ограничения

- Canvas хранит альфу в premultiplied-виде: полупрозрачные пиксели PNG при открытии и сохранении могут сместиться на шаг округления.
- PNG всегда сохраняется как 8-битный RGBA, поэтому серое изображение из GB7, сохранённое в PNG и открытое снова, покажет 32 бит.
- `colorSpaceConversion: 'none'` учитывает только Chromium; в Firefox и Safari цвета изображений со встроенным профилем могут немного отличаться.
- JPEG не хранит прозрачность: прозрачные пиксели накладываются на выбранный цвет фона.
- Очень большие изображения (> ~50 МП) открываются с предупреждением; GB7 ограничен 2^28 пикселями.

## Лабораторная работа 2. Цветовые каналы и «Пипетка»

### Панель каналов

- Число каналов зависит от изображения: 1 (серый), 2 (серый + альфа), 3 (RGB), 4 (RGB + альфа).
- У цветных изображений сверху строка «RGB» с цветной миниатюрой; щелчок по ней возвращает все цветовые каналы.
- Миниатюры каналов — в градациях серого (белый = максимум), альфа — чёрно-белая маска. Миниатюры уменьшаются собственной билинейной интерполяцией.
- Глаз включает или выключает канал (можно несколько); щелчок по самой строке показывает **только этот канал**. Последний видимый канал выключить нельзя. Включённые R, G, B отмечены полосой своего цвета.
- На холсте выключенный цветной канал обнуляется у всех пикселей. Если выключена альфа — пиксели показываются непрозрачными. Если оставлена только альфа — видна маска прозрачности в оттенках серого. Исходные пиксели не меняются: маска применяется при выводе.
- При открытии нового изображения все каналы снова включены.

### Пипетка

- Кнопка на панели инструментов или клавиша `I` (`V` — указатель).
- Щелчок левой кнопкой по холсту показывает в панели «Инфо» координаты X, Y относительно изображения, значения R, G, B (0–255), альфу, координаты CIELAB (L\*, a\*, b\*), образец цвета (слева без прозрачности, справа — с альфой поверх шахматки) и HEX.
- Значения берутся из текущей версии изображения, а не с экрана, поэтому выключенные каналы на них не влияют.
- CIELAB: sRGB → линейный RGB → XYZ (D65) → L\*a\*b\*, белая точка Xn = 0.95047, Yn = 1, Zn = 1.08883. Проверено на эталонных значениях (например, чистый красный → L\* 53.24, a\* 80.09, b\* 67.20).

## Лабораторная работа 3. Гистограмма и «Уровни»

Открывается через «Изображение → Уровни…» (`Ctrl/Cmd+L`) в нативном окне `<dialog>`.

### Гистограмма

- Столбчатая диаграмма (собственный SVG): по X — уровни 0…255, для изображений GB7 — 0…127; по Y — число пикселей.
- Для «Мастер» гистограмма строится по яркости каждого пикселя (BT.601: `0.299R + 0.587G + 0.114B`), для R, G, B и альфы — по выбранному каналу.
- Переключатель линейной и логарифмической шкалы по Y.

### Входные уровни

- Выпадающий список: «RGB (все)» (или «Серый (все)» для серых изображений), «Красный», «Зелёный», «Синий» и «Альфа» — если у изображения есть альфа-канал. Настройки каждого канала сохраняются при переключении.
- Три маркера под гистограммой и поля ввода: точка чёрного, полутона (гамма 0.1–9.9, 1.0 — линейно), точка белого. Чёрный не заходит за белый; маркер гаммы всегда между ними. Маркеры двигаются мышью и стрелками (`Shift` — шаг 10); нажатие в любом месте полосы захватывает ближайший маркер.
- Преобразование: `t = (v − чёрный) / (белый − чёрный)`, ограниченное 0…1, результат `t^(1/γ)`. Положение маркера полутонов `чёрный + (белый − чёрный)·0.5^γ`, поэтому сдвиг влево осветляет, вправо затемняет.
- Сначала применяются уровни отдельного канала, затем общие («Мастер»). Вычисление — через таблицы подстановки (LUT); у изображений GB7 результат остаётся в 7-битной сетке.

### Кнопки

- Окно не затемняет холст: оно стоит справа сверху и перетаскивается за заголовок (это по-прежнему модальный `<dialog>`). Гистограмма считается после открытия окна, поэтому большие изображения не задерживают его появление.
- «Предпросмотр» (включён по умолчанию): изменения сразу видны на холсте (не чаще одного кадра); при снятии холст возвращается к состоянию до открытия окна.
- «Сброс» возвращает уровни к исходным, не закрывая окно; «Отмена» закрывает окно без изменений; «Применить» создаёт новую версию изображения.
- «Изображение → Отменить» (`Ctrl/Cmd+Z`) возвращает предыдущую версию. Хранится до 10 версий (или ~512 МБ пикселей); при переполнении удаляется самая старая, кроме исходной.

## Лабораторная работа 4. Масштабирование

### Интерполяция

- Собственные реализации: **ближайший сосед** и **билинейная** (по умолчанию).
- Программный интерфейс расширяемый: метод описывается объектом `{ id, name, description, taps }`, который строит таблицу отсчётов по одной оси. Общий сепарабельный движок применяет её и для отображения, и для изменения размера, поэтому новый метод (например, бикубический) — это одна новая функция `taps` в реестре.
- Координаты по центрам пикселей: `src = (dst + 0.5) / масштаб − 0.5`, края повторяются.
- Цвет интерполируется с учётом альфы (premultiplied), поэтому на границе прозрачности не появляется тёмный ореол.
- Эти же реализации используются для холста и миниатюр каналов.

### Масштаб отображения

- В панели «Инфо»: список масштабов от 12 % до 300 % и ползунок. При изменении изображение перерисовывается, центр окна остаётся над той же точкой изображения.
- `Ctrl/Cmd + колесо` (и щипок на трекпаде) — плавный масштаб к точке под курсором.
- `Ctrl/Cmd+=` и `Ctrl/Cmd+−` — следующий и предыдущий масштаб, `Ctrl/Cmd+0` — вписать в окно, `Ctrl/Cmd+1` — 100 %.
- При открытии изображение целиком помещается в холст с отступами не менее 50 px, масштаб ограничен 12–300 %, значение в панели обновляется.
- Метод интерполяции отображения выбирается в «Инфо». На 100 % пиксели выводятся без интерполяции, чтобы изображение было резким.

### Изменение размера

«Изображение → Размер изображения…» (`Ctrl/Cmd+Alt+I`):

- число пикселей до и после в мегапикселях;
- единицы — пиксели или проценты;
- ширина и высота в выбранных единицах, флажок «Сохранять пропорции»;
- выбор алгоритма интерполяции и подсказка с его описанием и преимуществами;
- проверка ввода: число, целые пиксели от 1 до 16384, проценты до 1000 %, результат не меньше 1 px и не больше 100 МП; при ошибке кнопка «Применить» недоступна;
- пересчёт идёт в Web Worker: на кнопке индикатор, поля заблокированы, интерфейс не замирает;
- после подтверждения окно закрывается, новое изображение строится из текущей версии в полном разрешении (с уже применёнными уровнями) и показывается с текущим масштабом. Действие можно отменить `Ctrl/Cmd+Z`. Изображения GB7 после изменения размера остаются в 7-битной сетке.
