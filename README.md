# GrayBit Studio

**GrayBit Studio** — веб-редактор изображений для курса «Технологии компьютерной графики» (2026) — небольшой аналог Photoshop/GIMP. Все алгоритмы работы с пикселями написаны вручную; PNG и JPEG декодирует и кодирует браузер.

Ссылка на приложение: деплой пока не настроен.

## Архитектура (Feature-Sliced Design)

```
src/
  app/        точка входа, провайдеры, глобальные стили
  pages/      editor — страница редактора: собирает виджеты, диалоги, горячие клавиши
  widgets/    menu-bar · toolbar · canvas-viewport · side-panel · status-bar · editor-layout
  features/   open-file · save-file
  entities/   document (версии, отмена, текст статуса) · editor (состояние редактора на Zustand, вид)
  shared/     lib/image — все алгоритмы над пикселями (без DOM и React)
              lib/io — декодирование/кодирование браузером, скачивание
              ui — NativeDialog, CanvasView
              config — тема · lib/test — утилиты тестов
```

- Слой импортирует только нижележащие слои; срезы одного слоя друг друга не импортируют.
- Каждый срез и сегмент `shared` открывает публичный API через `index.ts`; импорт в обход него запрещён.
- Импорты через алиас `@/`. Правила проверяет [Steiger](https://github.com/feature-sliced/steiger) в составе `pnpm lint`.

## Производительность

- Холст размером с видимую область: кадр строится только из видимой части изображения, поэтому огромные файлы не упираются в лимиты canvas.
- Вывод разделён на дорогой этап (выборка видимой части, кешируется) и дешёвый шаг наложения на шахматку.
- История версий не копирует неизменённые буферы; лимит — 10 версий или ~512 МБ.

## Лабораторная работа 1. Цифровое представление изображения

### Возможности

- **Открытие:** «Файл → Открыть…», `Ctrl/Cmd+O` или перетаскивание файла в окно (из нескольких берётся первый). Форматы PNG, JPG/JPEG, GB7. Формат определяется **по сигнатуре файла**, а не по расширению.
- **Сохранение:** «Файл → Сохранить как…» (`Ctrl/Cmd+S`, `Ctrl/Cmd+Shift+S`) — имя файла, формат PNG / JPG / GB7; для JPG — качество 1–100 (по умолчанию 92) и цвет фона под прозрачными пикселями (по умолчанию белый); для GB7 — предупреждение о переводе в оттенки серого и режим маски (Авто / Всегда / Без маски). Сохраняется текущее изображение.
- **Строка состояния:** имя файла; ширина × высота, глубина цвета и формат, например `1920 × 1080 px · 24 бит (RGB) · PNG`, `512 × 512 px · 8 бит (7 + маска) · GB7`. Браузер всегда декодирует в 8-битный RGBA, поэтому настоящая глубина читается из заголовков: PNG (IHDR, tRNS) и JPEG (SOFn). Справа — текущий масштаб.
- **Холст:** размером с видимую область; изображение рисует собственный код, 1 пиксель изображения = 1 CSS-пиксель, резко на HiDPI. Прозрачность показана шахматкой, большие изображения прокручиваются. Пустой холст — кнопка «Открыть изображение»; при перетаскивании файла в окно появляется подсказка «Отпустите, чтобы открыть».
- **Интерфейс:** меню «Файл», панель инструментов слева, панель «Инфо» справа, тёмная тема.
- **Свои реализации:** кодек GB7, яркость BT.601 `Y = 0.299R + 0.587G + 0.114B` (перевод в серый для GB7), наложение прозрачности на цвет фона при сохранении в JPG, вывод изображения на холст.

### Формат GB7

| Смещение | Размер | Поле      | Значение                                     |
| -------: | -----: | --------- | -------------------------------------------- |
|        0 |      4 | сигнатура | `47 42 37 1D`                                |
|        4 |      1 | версия    | `01`                                         |
|        5 |      1 | флаги     | бит 0 — есть маска; биты 1–7 зарезервированы |
|        6 |      2 | ширина    | uint16, big-endian                           |
|        8 |      2 | высота    | uint16, big-endian                           |
|       10 |      2 | резерв    | `0000`                                       |
|       12 |    W×H | пиксели   | по байту, построчно с левого верхнего угла   |

Биты 6–0 пикселя — серое 0–127, бит 7 — маска (1 — видим, 0 — прозрачен), если в заголовке есть флаг маски.

> В тексте задания маска один раз названа «бит 0». Это опечатка: по структуре байта маска — **бит 7**, так и реализовано.

- **Декодирование:** серое масштабируется как `round(v·255/127)`. Ошибки проверяются строго по порядку: длина, сигнатура, версия, нулевой размер, предел 2^28 пикселей, обрезанные данные (до выделения памяти). Зарезервированные биты флагов и лишние байты в конце игнорируются; без флага маски бит 7 игнорируется.
- **Кодирование:** серое `round(Y·127/255)` по BT.601. Маска: «Авто» — ставится, если есть альфа < 128; «Всегда» — бит 7 = альфа ≥ 128; «Без маски» — альфа отбрасывается. Если исходный файл был GB7 с маской, по умолчанию «Всегда», иначе «Авто». Стороны больше 65535 — ошибка.
- Все 128 уровней серого переживают цикл декодирование → кодирование; канонические файлы GB7 воспроизводятся байт в байт (проверено на файлах из LMS в `test-images/`).

### Ограничения

- Canvas хранит альфу в premultiplied-виде: полупрозрачные пиксели PNG при открытии и сохранении могут сместиться на шаг округления.
- PNG всегда сохраняется как 8-битный RGBA, поэтому серое изображение из GB7, сохранённое в PNG и открытое снова, покажет 32 бит.
- `colorSpaceConversion: 'none'` учитывает только Chromium; в Firefox и Safari цвета изображений со встроенным профилем могут немного отличаться.
- JPEG не хранит прозрачность: прозрачные пиксели накладываются на выбранный цвет фона.
- Очень большие изображения (> ~50 МП) открываются с предупреждением; GB7 ограничен 2^28 пикселями.
